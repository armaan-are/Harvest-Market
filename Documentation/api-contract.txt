API Contract

This document describes the backend API for the Local Farm Marketplace project.
Routes return JSON and are backed by SQLite.

Base URL:
http://localhost:8000

Authentication:
Protected routes expect this header:
Authorization: Bearer <token>

The token is returned by POST /api/login.

GET /api/health
Purpose: Confirm the backend is running.
Input: none
Output:
- status: string
- message: string

GET /api/categories
Purpose: List marketplace categories.
Input: none
Output:
- array of category objects
- id: integer
- name: string

POST /api/register
Purpose: Create a buyer or seller account.
Input:
- email: string
- password: string
- role: string, either "buyer" or "seller"
Output:
- message: string
- userId: integer

POST /api/login
Purpose: Log in and create a session token.
Input:
- email: string
- password: string
Output:
- message: string
- token: string
- role: string
- email: string
- userId: integer

GET /api/products
Purpose: List marketplace products with sorting and filters.
Input:
- sort: string, optional. Allowed values: default, price_asc, price_desc, popular
- category: string, optional. Example: produce, dairy, meat, baked_goods
- zipCode: string, optional 5-digit farm zip code
Output:
- array of product objects
Product fields:
- id: integer
- title: string
- description: string
- price: float
- quantity_available: integer
- quantity_reserved: integer
- image_url: string
- seller_id: integer
- purchase_count: integer
- farm_name: string
- zip_code: string
- category: string
- average_rating: float

POST /api/products
Purpose: Create a product listing as a seller.
Authentication: seller required
Input:
- title: string
- description: string
- price: float
- quantity_available: integer
- category: string
- image_url: string
Output:
- message: string
- productId: integer

PUT /api/products/<product_id>
Purpose: Update a seller's own product.
Authentication: seller required
Input:
- product_id: integer path parameter
- title: string
- description: string
- price: float
- quantity_available: integer
- category: string
- image_url: string
Output:
- message: string

DELETE /api/products/<product_id>
Purpose: Delete a seller's own product.
Authentication: seller required
Input:
- product_id: integer path parameter
Output:
- message: string

POST /api/uploads
Purpose: Upload a product image file.
Authentication: seller required
Input:
- multipart form field "image"
Accepted extensions:
- .jpg
- .jpeg
- .png
- .gif
- .webp
Output:
- imagePath: string

GET /uploads/<filename>
Purpose: Serve an uploaded image.
Input:
- filename: string path parameter
Output:
- image file response

GET /api/orders
Purpose: List the current user's buyer orders or seller incoming requests.
Authentication: buyer or seller required
Input:
- status: string, optional. Allowed values: all, pending, confirmed, ready_for_pickup, completed, rejected, cancelled
Output:
- array of order objects
Order fields:
- id: integer
- buyer_id: integer
- seller_id: integer
- status: string
- pickup_window: string
- created_at: string
- updated_at: string
- product_id: integer
- product_title: string
- image_url: string
- quantity: integer
- unit_price: float
- total_price: float
- buyer_email: string
- seller_email: string
- farm_name: string

POST /api/orders
Purpose: Create a pending pickup order and reserve inventory.
Authentication: buyer required
Input:
- productId: integer
- quantity: integer
- pickupWindow: string
Output:
- message: string
- orderId: integer

PUT /api/orders/<order_id>/status
Purpose: Advance, reject, or cancel an order.
Authentication: buyer or seller required
Input:
- order_id: integer path parameter
- status: string
Allowed transitions:
- pending to confirmed, rejected, or cancelled
- confirmed to ready_for_pickup
- ready_for_pickup to completed
Role rules:
- sellers can manage their own incoming orders
- buyers can only cancel their own pending orders
Output:
- message: string

POST /api/purchases
Purpose: Backward-compatible route that creates a pending order.
Authentication: buyer required
Input:
- productId: integer
- quantity: integer
- pickupWindow: string, optional
Output:
- message: string
- orderId: integer

GET /api/profile
Purpose: Fetch the current user's profile.
Authentication: buyer or seller required
Input: none
Buyer output:
- role: string
- email: string
- full_name: string
- phone: string
- home_zip: string
Seller output:
- role: string
- email: string
- farm_name: string
- biography: string
- pickup_address: string
- operating_hours: string
- zip_code: string

PUT /api/profile
Purpose: Update the current user's role-specific profile.
Authentication: buyer or seller required
Buyer input:
- full_name: string
- phone: string
- home_zip: string, optional 5-digit zip code
Seller input:
- farm_name: string
- biography: string
- pickup_address: string
- operating_hours: string
- zip_code: string, optional 5-digit zip code
Output:
- updated profile object

GET /api/messages?productId=<product_id>
Purpose: Return visible product-linked messages.
Authentication: buyer or seller required
Input:
- productId: integer query parameter
Output:
- array of message objects
Message fields:
- id: integer
- product_id: integer
- order_id: integer or null
- buyer_id: integer
- seller_id: integer
- sender_id: integer
- sender_role: string
- sender_email: string
- content: string
- created_at: string

POST /api/messages
Purpose: Send a product-linked message.
Authentication: buyer or seller required
Input:
- productId: integer
- content: string
Output:
- message: string
- messageId: integer

GET /api/reviews
Purpose: List verified reviews.
Input:
- farmerId: integer, optional
Output:
- array of review objects
Review fields:
- id: integer
- order_id: integer
- buyer_id: integer
- farmer_id: integer
- rating: integer
- comment: string
- created_at: string
- buyer_email: string
- farm_name: string

POST /api/reviews
Purpose: Create a verified review for a completed order.
Authentication: buyer required
Input:
- orderId: integer
- rating: integer from 1 to 5
- comment: string
Rules:
- order must belong to the buyer
- order status must be completed
- one review is allowed per order
Output:
- message: string
- reviewId: integer
